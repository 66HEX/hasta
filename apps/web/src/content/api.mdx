## API reference

Positions and margins use viewport CSS pixels; durations use milliseconds. Timestamps use the document's performance clock, not Unix time. Import shared types from your adapter's entrypoint.

### Entrypoints

Hasta is ESM. Adapters support React 19, Vue 3.5+, Svelte 5.32+, and Solid 1.9+; install only the framework you use. Vanilla has no framework dependency.

| Import                 | Exports                                                          |
| ---------------------- | ---------------------------------------------------------------- |
| `@66hex/hasta/vanilla` | `createHastaController`, `createHasta`                           |
| `@66hex/hasta/react`   | `useHasta`, `useHastaTarget`                                     |
| `@66hex/hasta/vue`     | Same helpers, accepting reactive refs/getters                    |
| `@66hex/hasta/svelte`  | `useHasta`; action `hastaTarget`; attachment `attachHastaTarget` |
| `@66hex/hasta/solid`   | `useHasta`, `useHastaTarget`, accepting reactive getters         |
| `@66hex/hasta/core`    | DOM-free geometry, `KalmanPredictor`, and spatial index          |

`@66hex/hasta/core` also exports `KalmanOptions` for the predictor's options and `KalmanPrediction` for its two-point forecast. `KalmanPredictor` exposes `update(sample)`, `predict(now, horizonMs)`, `intersectRect(now, horizonMs, rect)`, and `reset()`.

Prefer the controller for a shared API across frameworks. The lower-level `createHasta()` requires a browser document: call `track(element)`, then `target.when(condition, callback, options)`, which returns an unsubscribe function. Its targets expose `getBounds()`, `invalidate()`, and `untrack()`.

### Solid helpers

Call `useHasta()` and `useHastaTarget()` during component setup or inside an owned Solid scope. The controller connects on mount and is destroyed when its owner is disposed. Target bindings have their own cleanup, so a child can release its target while a shared controller stays connected.

Both helpers accept plain options or getters. For reactive values, use `useHasta(() => ({ horizonMs: horizon() }))` and `useHastaTarget(hasta, () => ({ when: { type: 'intersects', withinMs: horizon() }, onPredict }))`. Read signals and props inside the getter; passing their current values in a plain object captures those values once. Each update replaces the options, so include every option you want to keep.

Use `ref={target.ref}` on an HTML element. The ref detaches when its Solid scope is disposed, including a conditional `Show` branch. A binding tracks one element at a time. For DOM managed outside Solid, call `target.ref(null)` when removing the element.

The controller argument can also be a getter, such as `useHastaTarget(() => props.hasta, options)`. Switching controllers transfers the target and cancels its previous subscription. Callback and option updates on the same controller reuse the binding.

### Controller options

| Option           | Default          | Meaning                                     |
| ---------------- | ---------------- | ------------------------------------------- |
| `horizonMs`      | `120`            | Forecast length for custom predicates       |
| `maxSampleAgeMs` | `100`            | Maximum age of the latest mouse sample      |
| `bounds`         | `'frame'`        | Measure during active frames; the only mode |
| `debug`          | `false`          | Boolean or [overlay options](#debugging)    |
| `onError`        | Console reporter | Receives callback failures                  |
| `document`       | Current document | Browser document to track                   |

### Controller methods

| Method                       | Effect                                                  |
| ---------------------------- | ------------------------------------------------------- |
| `connect()` / `disconnect()` | Start / release the engine; preserve bindings           |
| `updateOptions(options)`     | Replace configuration; omitted fields reset to defaults |
| `target(options)`            | Create a reusable binding                               |
| `pause()` / `resume()`       | Suspend / resume prediction                             |
| `setDebug(options)`          | Enable, disable, or configure the overlay               |
| `getDebugSnapshot()`         | Latest debug state, or `null` when off/disconnected     |
| `destroy()`                  | Permanently release the controller and bindings         |

### Target options

Pass these to `controller.target()` or your framework's target helper.

| Option                | Default  | Meaning                                                         |
| --------------------- | -------- | --------------------------------------------------------------- |
| `when`                | Required | Intersection rule or `(context) => boolean`                     |
| `when.withinMs`       | Required | Arrival deadline for `intersects`                               |
| `when.marginPx`       | `0`      | Expand every edge of the rectangle                              |
| `when.includeCurrent` | `false`  | Include current contact and observed crossings with zero ETA    |
| `onPredict`           | Required | `(event) => void \| Promise<void>`                              |
| `once`                | `false`  | Start at most once per subscription                             |
| `stableForMs`         | `0`      | Span of matching observations before a forecast callback starts |
| `cooldownMs`          | `0`      | Minimum interval between starts                                 |

`horizonMs`, `maxSampleAgeMs`, and `withinMs` must be finite and positive. `marginPx`, `stableForMs`, and `cooldownMs` must be finite and nonnegative.

New forecast callbacks require a new measurement timestamp, for both intersection conditions and custom predicates. Animation frames, same-time corrections, and cooldown expiry alone cannot start or restart them. With `includeCurrent`, confirmed contact can complete `stableForMs` while the pointer remains still.

Intersection rules use bounded release hysteresis: an active speculative match can survive a near miss for up to 32 ms within an extra 6 px margin. A turn or substantial slowdown ends retention sooner. The extra margin never starts a callback, and `stableForMs` still controls activation only. Custom predicates retain their immediate cancellation behavior.

### Target binding

| Method            | Effect                                                              |
| ----------------- | ------------------------------------------------------------------- |
| `ref(element)`    | Attach an HTML element; `null` detaches and allows reuse            |
| `update(options)` | Replace the rule and callback options                               |
| `getBounds()`     | Latest `{ rect, measuredAt }`; `null` until usable or when detached |
| `invalidate()`    | Request measurement on the next scheduled pass                      |
| `destroy()`       | Permanently dispose of the binding                                  |

### Intersection event

| Field                        | Value                                                           |
| ---------------------------- | --------------------------------------------------------------- |
| `element`                    | Registered HTML element                                         |
| `rect`, `measuredAt`         | `{ minX, minY, maxX, maxY }` and measurement time               |
| `forecast`                   | `generatedAt` and trajectory `points` with `{ x, y, offsetMs }` |
| `intersection`               | First entry `{ point: { x, y }, etaMs }`                        |
| `etaMs`                      | Time until entry, relative to evaluation                        |
| `predictedAt`, `evaluatedAt` | Entry timestamp and evaluation timestamp                        |
| `signal`                     | `AbortSignal` tied to this match                                |

A custom predicate receives `PredictionContext` and still runs on every evaluated frame. Geometry or external-state changes can cancel a match, but starting its callback also requires a new measurement. Its callback receives `PredictionEvent`: `intersection` can be `null`, and top-level `etaMs` / `predictedAt` are absent.

### Debugging

Set `debug: true` at creation or call `setDebug(true)`; use `setDebug(false)` to hide the overlay. It ignores pointer events and is removed on disconnect. Bounds, trajectory, intersections, labels, and the compact panel are enabled by default. Add `samples: true` for a short mouse trail, or `panel: false` to hide the summary.

| Flag                       | Shows                                              |
| -------------------------- | -------------------------------------------------- |
| `bounds`, `trajectory`     | Target rectangles, outer margin, and forecast path |
| `samples`, `intersections` | Recent mouse samples and first entry points        |
| `labels`                   | Target names and dimensions, where space permits   |
| `panel`                    | Status, target count, and forecast horizon         |

`getDebugSnapshot()` includes status, forecast, samples, velocity, target rectangles, and rule state. Turn debug off when finished.
